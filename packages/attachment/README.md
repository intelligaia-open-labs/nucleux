# @nucleux/attachment

Attachment — removable file and image context tiles for the composer — Nucleux agentic UI for React.

Part of **[Nucleux](https://github.com/intelligaia-open-labs/nucleux)** — agentic UI components for React. Install a single component, or the full kit via [`@nucleux/react`](https://www.npmjs.com/package/@nucleux/react).


## Exports

- **`Attachment`** — removable file and image context tiles for the composer
- **`AttachmentGroup`** — Flex-wrap container that lays out `<Attachment>` items with consistent gaps.

## Install

```bash
pnpm add @nucleux/attachment @nucleux/tokens
```

`react` / `react-dom` are peer dependencies.

## Usage

```tsx
import { Attachment } from "@nucleux/attachment";
```

Requires the theme once in your app: `import "@nucleux/tokens/styles.css";`
and the Tailwind preset from `@nucleux/tokens/preset`.
