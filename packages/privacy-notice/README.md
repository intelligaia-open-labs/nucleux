# @nucleux/privacy-notice

PrivacyNotice — a notice that a chat is ephemeral or private — Nucleux agentic UI for React.

Part of **[Nucleux](https://github.com/intelligaia-open-labs/nucleux)** — agentic UI components for React. Install a single component, or the full kit via [`@nucleux/react`](https://www.npmjs.com/package/@nucleux/react).

## Install

```bash
pnpm add @nucleux/privacy-notice @nucleux/tokens
```

`react` / `react-dom` are peer dependencies.

## Usage

```tsx
import { PrivacyNotice } from "@nucleux/privacy-notice";
```

Requires the theme once in your app: `import "@nucleux/tokens/styles.css";`
and the Tailwind preset from `@nucleux/tokens/preset`.
